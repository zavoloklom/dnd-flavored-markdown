# Описание

D&D-Flavored Markdown (DFM) - надстройка над CommonMark с минимальным набором расширений,
ориентированных на вёрстку «книги правил/модуля» и печать в PDF. Ставка на совместимость, модульность и предсказуемую
пагинацию.

Ориентиры - [GitLab Flavored Markdown](https://docs.gitlab.com/user/markdown/) и [homebrewery](https://homebrewery.naturalcrit.com/)

https://docusaurus.io/docs/markdown-features/admonitions

## Цели и принципы

* Совместимость. Базовый Markdown остаётся валидным. Любые расширения — это опциональные «контейнеры» и атрибуты.
* Детерминированная печать. То, что видите в HTML, предсказуемо попадает в PDF (CSS Paged Media + чёткие правила разбиения страниц).
* Тема ≠ движок. Темы (шрифты, цвета, рамки) подключаются как «скины». Ядро отвечает за семантику и структуру.
* Минимум магии. Никаких скрытых автопревращений, только явные конструкции.
* Воспроизводимость. Один и тот же исходник даёт одинаковый результат в CI/CD.

## Архитектура рендера

* Парсер: любой CommonMark-совместимый (чтобы не изобретать велосипед), плюс плагин DFM.
* AST-плагины: расширения для специальных блоков (статблоки, сайдбары, «сокровища», карты).
* Рендер: HTML + CSS (экран) и отдельный print-CSS с поддержкой колонок, полей, колонтитулов, оглавления.
* PDF: движок поверх браузера (Playwright/Puppeteer) или CSS-движки для пагинации (например, движки с поддержкой Paged Media).
* CLI и веб-редактор: CLI для сборки в CI; веб-редактор для предпросмотра и экспорта.

## Синтаксический дизайн (без кода, концептуально)

* Фронтматтер: единый YAML/JSON-блок в начале документа для генерации метаданных.
* Контейнеры: «обёртки» вокруг стандартных параграфов/списков/таблиц с типом и опциями.
* Атрибуты: лёгкий способ задавать параметры (размер изображения, иконку, цветовую схему, колонность, приоритет, вариацию темы).
* Директивы в тексте: короткие маркеры для кубов (d20), DC, урона, условий — чтобы движок мог унифицировать формат.
* Кросс-ссылки: удобные человекочитаемые ярлыки; автопроверка «битых» ссылок.

## Печать и пагинация

* Чёткие правила разрыва: запрет разрыва внутри статблока, бокса «читка вслух», таблицы; опции «держать с заголовком».
* Колонки: стабильная сетка с предикативным переносом; никаких «случайных» переливов.
* Автооглавление и колонтитулы: из фронтматтера и структуры документа.

Приоритет внедрения (по шагам)

Базовая структура: фронтматтер, заголовки, колонтитулы, TOC, разрывы страниц.
Контейнеры: «Бокс-текст», «Совет Мастеру», «Опасность».
Статблок v1 (монстр/NPC) + таблички навыков/лут.
Пагинация и колонки в печати (устойчивость переносов).
Темы/скины и «ч/б» профиль.
Кросс-ссылки, индексы, генераторы бросков.
Редактор с предпросмотром, линтер, CI-сборка.
Карты, режимы «GM/Player», пакет импорта/экспорта.

Блоки контента (минимально необходимый набор)

Страницы и колонки
Правила разметки для: стандартной страницы, разворота, 1/2/3-колоночной вёрстки.
Жёсткие разрывы страницы/колонки, запрет висячих заголовков.
Колонтитулы и метаданные
Фронтматтер (title, subtitle, authors, setting, level range, version, revision).
Автоколонтитулы: название приключения, глава, номер страницы.
Оглавление, список иллюстраций, индексы
Автогенерация TOC по уровням заголовков.
Кросс-ссылки и якоря (разделы, монстры, предметы).
Выделенные контейнеры (callouts)
«Важное», «Совет Мастеру», «Лор», «Опасность», «Хук», «Бокс-текст» (читка вслух).
Варианты с пиктограммами и цветовой кодировкой.
Статблоки
Универсальный блок сущности (монстр/NPC/ловушка) с полями: имя, размер/тип/мировоззрение, КД, хиты, скорости, характеристики, навыки, уязвимости/сопротивления/иммунитеты, чувства, языки, ОУ, пассив. восприятие, черты, действия/реакции/легендарные/логовские.
Поддержка альтернативных шаблонов (например, для магических предметов и заклинаний).
Таблицы бросков и генераторы
Упрощённые таблицы d20/d100, пометки «rollable» с автоподсветкой куба.
Свёртываемые «генераторы» (для веб-версии) с фиксированным видом в печати.
Карты и схемы
Вставки с подписью, масштабом, легендой; варианты «для Мастера»/«для игроков».
Опциональные гриды и водяные знаки «Player/GM».
Сцены и структура главы
Семантические блоки: «Локация», «Сцена», «Навык-чек», «Исходы/Эскалация».
Маркеры сложности и ожидаемого уровня.
Лут/Награды
Контейнеры для сокровищ/опыта/репутации.
Правила безопасности и доступности
Встроенные блоки для контент-нотов (X-card и аналоги), предупреждения о темах.

Где «проявить характер»

«Генераторные» блоки: один и тот же источник даёт интерактив в вебе и детерминированную таблицу в PDF.
Семантика сцен и исходов: пригодно для подготовки и повторного использования контента.
Скины как npm-пакеты: авторы приключений публикуют свои стилистические темы, не касаясь ядра.
Статические предпросмотры в MR: каждый Merge Request показывает готовую PDF-версию для ревью без локальной сборки.
