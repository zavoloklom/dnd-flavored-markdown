# Описание

D&D-Flavored Markdown (DFM) - надстройка над CommonMark с минимальным набором расширений,
ориентированных на вёрстку «книги правил/модуля» и печать в PDF. Ставка на совместимость, модульность и предсказуемую
пагинацию.

Ориентиры - [GitLab Flavored Markdown](https://docs.gitlab.com/user/markdown/) и [homebrewery](https://homebrewery.naturalcrit.com/)

Ориентир для дополнительных блоков - [admonitions у docusaurus](https://docusaurus.io/docs/markdown-features/admonitions)

## Цели и принципы

* Совместимость. Базовый Markdown остаётся валидным. Любые расширения — это опциональные «контейнеры» и атрибуты.
* Детерминированная печать. То, что видите в HTML, предсказуемо попадает в PDF (CSS Paged Media + чёткие правила разбиения страниц).
* Тема ≠ движок. Темы (шрифты, цвета, рамки) подключаются как «скины». Ядро отвечает за семантику и структуру.
* Минимум магии. Никаких скрытых автопревращений, только явные конструкции.
* Воспроизводимость. Один и тот же исходник даёт одинаковый результат в CI/CD.

## Архитектура рендера

* Парсер: любой CommonMark-совместимый, плюс плагин DFM.
* AST-плагины: расширения для специальных блоков (статблоки, сайдбары, «сокровища», карты).
* Рендер: HTML + CSS (экран) и отдельный print-CSS с поддержкой колонок, полей, колонтитулов, оглавления.
* PDF: движок поверх браузера (Playwright/Puppeteer) или CSS-движки для пагинации (например, движки с поддержкой Paged Media).
* CLI и локальное preview: CLI для сборки в CI; локальное preview для предпросмотра и экспорта.

## Синтаксический дизайн (без кода, концептуально)

* Фронтматтер: единый YAML/JSON-блок в начале документа для генерации метаданных.
* Контейнеры: «обёртки» вокруг стандартных параграфов/списков/таблиц с типом и опциями.
* Атрибуты: лёгкий способ задавать параметры (размер изображения, иконку, цветовую схему, колонность, приоритет, вариацию темы).
* Директивы в тексте: короткие маркеры для кубов (d20), DC, урона, условий — чтобы движок мог унифицировать формат.
* Кросс-ссылки: удобные человекочитаемые ярлыки; автопроверка «битых» ссылок.

## Печать и пагинация

* Чёткие правила разрыва: запрет разрыва внутри статблока, бокса «читка вслух», таблицы; опции «держать с заголовком».
* Колонки: стабильная сетка с предикативным переносом; никаких «случайных» переливов.
* Автооглавление и колонтитулы: из фронтматтера и структуры документа.
