# Что чем меряем

## Геометрия макета

* Формат страницы, поля, отступы блоков, колонки, gap, большие радиусы → **mm** (или cm).
* Пример: `@page{size:A4;margin:0}` и `.page{width:210mm;height:297mm;padding:14mm 19mm 17mm}`.

## Типографика

* Кегль (`font-size`) → **pt** (или `rem` с базой в pt).

  * Пример: `html{font-size:10.5pt}`.
* Межстрочный:

  * Рекомендуемо — **unitless** множитель: `line-height:1.35` (масштабируется вместе с кеглем, не ломает базовую сетку).
  * Если нужен **абсолютный** интерлиньяж (жёсткая базовая сетка) — **pt**.
    Пример: базовая строка 14 pt → `body{line-height:14pt}`; заголовок `h2{font-size:16pt; line-height:21pt}`.
* Межбуквенный (`letter-spacing`) → по умолчанию **em** (относительно кегля).

  * Текст: `0` (или очень малые значения `0.005em–0.02em` по вкусу шрифта).
  * Малые капители/крупные заголовки: `0.02–0.05em`.
  * Если нужна фиксированная величина для конкретного макета — **pt** (например, `0.25pt`), но тогда следить за каждым размером шрифта.
* Межсловный (`word-spacing`) → **em** (обычно не трогаем).

## Линии, границы, тени, иконки

* Границы (контуры, hairline) → **px**.

  * Почему px: в CSS печати `1px = 1/96in ≈ 0.2646 mm ≈ 0.75 pt`. Рендерер гарантирует «волосяную» толщину независимо от масштаба; это привычный «эталон» для тонких линий. Поддерживаются и дробные: `0.5px` (ещё тоньше).
  * Если нужна «толстая» рамка — можно в **mm** (например, `0.5mm`).
* Тени (`box-shadow`, `text-shadow`, blur/offset) → **px** (алгоритмы браузера настроены в пикселях).
* Малые радиусы скругления → **px**; крупные (карточки/рамки) → **mm**.

## Изображения и иконки

* Размеры в макете (независимо от формата исходника, растровый/векторный) задаём в **mm** или в **% ширины колонки**.

  * Рекомендация для DFM: фиксируй **мм**, чтобы совпадало с физикой колонок.
  * Примеры:
    – во всю колонку: `img{width:82mm; max-width:100%; height:auto}`
    – на две колонки: `width:172mm`.
    (при padding 19 мм слева/справа и `gap:8 мм` у A4 колонка ≈ **82 мм**)
* SVG-иконки, привязанные к текста (inline) → можно в **em** (`width:1em;height:1em`), чтобы масштабировались с шрифтом.

## «Нельзя/нежелательно» в печати

* `%`, `vh`, `vw`, высоты в процентах — непредсказуемы на бумаге.
* `transform: scale()` для подгонки — ломает толщины линий и оптический размер шрифта.
* `overflow: clip` на `.page` — отрежет хвосты на границе листа.

# Короткие ответы на твои вопросы

**1) Абсолютный `line-height` — в чём?**
В **pt**. Делай кратным базовой строке (например, 14 pt, 21 pt). Если отпускать абсолютность — лучше без единиц (множитель).

**2) Почему `border`/тени в px?**
`px` в печати — device-independent (1/96 дюйма). Тонкие линии выглядят стабильно и предсказуемо при любом масштабе. Для «жирных» рамок можно использовать **mm**. Тени и размытия исторически параметризуются в px — так браузеры рассчитывают гаусс.

**3) `letter-spacing` — в чём?**
По умолчанию **em** (масштабируется с кеглем). Для микронастройки конкретного титула — **pt**. Типичные значения:

* текст: `0` … `0.01em`;
* капители/мелкий кегль: `0.02em`;
* крупные заголовки: `0.02–0.05em`;
* абсолютный трекинг: `0.25pt` или `0.5pt` (проверять на конкретном шрифте).

**4) Картинки — без расчётов DPI?**
Да. В CSS всегда задавай **физический размер** (в **mm**) под сетку колонок. Растр сам масштабируется; просто следи, чтобы исходник был не хуже ~300 DPI под выбранную ширину (рекомендация к авторам контента, не к CSS).

# Мини-шаблон для документации

```css
/* Страница и колонки (A4) */
@page { size: A4; margin: 0; }
.page{
  width:210mm; height:297mm; box-sizing:border-box;
  padding:14mm 19mm 17mm 19mm;
  column-count:2; column-gap:8mm; column-fill:auto;
  break-after:always;
}

/* Типографика */
html{ font-size:10.5pt; }      /* база в pt */
body{ line-height:1.4; }       /* относительный интерлиньяж */
h1{ font-size:22pt; line-height:26pt; letter-spacing:0.02em; }
h2{ font-size:16pt; line-height:21pt; }
small{ letter-spacing:0.01em; }

/* Линии/тени */
.rule{ border-top:1px solid rgba(0,0,0,.2); }
.card{ border:1px solid rgba(0,0,0,.15); border-radius:2mm; box-shadow:0 2px 6px rgba(0,0,0,.06); }

/* Картинки */
img.figure{ width:82mm; max-width:100%; height:auto; }   /* ширина колонки */
img.figure--wide{ width:172mm; }
```
