# Авто-футер страниц (footnote) и главы — спецификация

Ниже — договорённости по «короткой подписи страницы» (footnote) и связи с главами. Это **только документация**, без кода.

---

## Кратко

* На каждой странице можно выводить **footnote** — короткую подпись внизу.
* Источник подписи:

    1. **Явный текст** на странице: `::: page {footnote="…"}`
    2. **Авто**: `footnote="auto"` — взять из **главы** (`::: chapter …`).
    3. **Отключить**: `footnote="none"`.
* По всему документу можно задать **дефолт** во фронтматтере:
  `footnote: auto | none | "<текст>"`.

Дополнительно: при нарезке контента на страницы движок пишет на `<section class="page">` атрибут
**`data-chapter="…"``** — «актуальная» глава для этой страницы (см. ниже правила).  
Никаких других `data-*` для главы не добавляется.

---

## Правила вычисления footnote для страницы

Для каждой страницы рассчитывается **итоговый текст футера** по приоритетам:

1. **Локально задано отключение**
   `::: page {footnote="none"}` → футер **не рисуем**.

2. **Локально задан текст**
   `::: page {footnote="Интерлюдия"}` → используем **этот текст**.

3. **Локально `auto`**
   `::: page {footnote="auto"}` → берём подпись из **главы** (см. «Откуда берётся глава» ниже):

    * если глава имеет вид `A | B` → футер `"A | B"`;
    * если только `B` → футер `"B"`;
    * если главы не нашли → футер **пуст** (ничего не рисуем).

4. **Ничего не задано локально** → смотрим **фронтматтер**:

    * `footnote: none` → не рисуем;
    * `footnote: "<текст>"` → используем этот текст;
    * `footnote: auto` → как в п.3;
    * ключа нет → **ничего** (по умолчанию футер не выводится).

> Локальное всегда сильнее глобального.

---

## Откуда берётся «глава» для страницы

При разбиении на страницы:

* Движок отслеживает позиции всех `<div class="chapter">…</div>` в потоке.
* Для каждой страницы «её» глава — это:

    1. Первая **на самой странице** (если есть), иначе
    2. **Ближайшая предыдущая** по документу (последняя встреченная выше).

Затем на `<section class="page">` записывается:

```html
<section class="page" data-page-count="…" data-chapter="Глава 1 | Прибытие">…</section>
```

* Если на момент страницы актуальной главы нет — атрибут `data-chapter` **не ставится**.

> Опционально автор может вручную переопределить данные:
> `::: page {chapter="Глава 1 | Пролог"}` — это перезапишет `data-chapter` для данной страницы; при `footnote="auto"` будет использовано именно оно.

## Примеры использования

### Глобально авто-футер из глав

```yaml
---
footnote: auto
---
```

```md
::: page <!-- на этой странице футер это "Глава 1 | Прибытие" -->

::: chapter Глава 1 | Прибытие

…контент…

::: page {footnote="none"}      <!-- на этой странице футер скрыт -->
…контент…

::: page <!-- на этой странице футер это "Глава 1 | Прибытие" -->
…контент…

::: page <!-- на этой странице футер это "Глава 2 | Погоня" -->

::: chapter Глава 2 | Погоня
…контент…
```

### Явная замена на одной странице

```md
::: page {footnote="Интерлюдия"}
…контент…
```

### Локальное авто и ручное переопределение главы

```md
::: page {chapter="Глава 1" footnote="auto"}
…контент…
```

(Футер возьмёт «Глава 1», даже если реальная ближайшая глава другая.)

## Вёрстка (подсказки)

* Футер страницы рисуется внизу, независимо от колонок:

  ```css
  .page { position: relative; padding-bottom: var(--page-footer-space, 14mm); }

  .page > .footnote {
    position: absolute;
    left: 0; right: 0; bottom: 12mm;
    column-span: all; -webkit-column-span: all;
    text-align: left;
    opacity: .85;
    pointer-events: none;
  }
  ```
* Номер страницы (если включён) и footnote могут сосуществовать (например, номер по центру ниже).

---

## Краевые случаи

* Несколько `chapter` на странице — берём **первую сверху**.
* Глава стоит сразу после `page`-разрыва — она относится к **текущей** странице.
* `footnote="auto"`, главы нет нигде — футер **не рисуем**.
* i18n не вмешивается: содержимое `chapter` считается авторским текстом. Если нужен перевод — автор сам маркирует фрагменты `data-i18n-key` внутри `chapter`.

---

## Что записывается на страницу

На `<section class="page">` гарантированно будут:

* `data-page-count="…"` — порядковый номер страницы (как и раньше),
* **`data-chapter="…"`** — строка главы для этой страницы (если определена).

Других `data-*` для главы **нет**.
