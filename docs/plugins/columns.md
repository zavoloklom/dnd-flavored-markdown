# Документация: Колоночная вёрстка DFM

## Общая модель

* Колонки задаются на «странице»: `.page { column-count: 2; column-gap: … }`
* Разрывы и широкие блоки управляются **маркерами/контейнерами** ниже.

---

## 1) `::: columnbreak`

**Назначение:** перейти в **следующую колонку** на текущей странице.

**Синтаксис:**

```md
::: columnbreak
```

**Что генерится:**
`<div class="columnbreak"></div>`

**CSS-ожидания:**

```css
.dfm-colbreak{
  break-before: column;
  -webkit-column-break-before: always;
  column-break-before: always;
}
```

**Нюансы:**

* Если уже на правой колонке (при `column-count: 2`), большинство движков начнут **следующий ряд** колонок ниже — итог как у «переноса на новую строку колонок».
* Для печати поведение сохраняется.

**Пример:**

```md
Текст слева…

::: columnbreak
Текст справа той же страницы.
```

---

## 2) `::: columnreset`

**Назначение:** «обнулить» поток колонок — начать **новый ряд** колонок, т.е. снова писать **с левой**.

**Синтаксис:**

```md
::: columnreset
```

**Что генерится:**
`<div class="columnreset"></div>`

**CSS-ожидания:**

```css
.dfm-colreset{
  column-span: all;   /* закрывает текущие колонки и начинает новый ряд */
  display: block;
  height: 0; margin: 0; padding: 0; border: 0;
}
```

**Применение:**

* После длинного правого столбца, чтобы следующий блок гарантированно начался слева.
* Перед крупными заголовками разделов, если не используете автоматическое правило.

**Опционально (автосброс на H1):**

```css
.dfm-page h1 { column-span: all; }
```

**Пример:**

```md
Левая колонка…

::: columnbreak
Правая колонка…

::: columnreset
Снова левая колонка (новый ряд).
```

---

## 3) `::: wide … :::`

**Назначение:** блок, который **игнорирует колонки** и занимает **всю ширину страницы**. Подходит для больших иллюстраций, таблиц, «шапок» разделов и пр.

**Синтаксис:**

```md
::: wide
Любой Markdown-внутри — будет растянут на всю ширину.
:::
```

**Что генерится:**

```html
<div class="wide">
  …inner HTML…
</div>
```

**CSS-ожидания:**

```css
.wide{
  column-span: all;   /* вытягивает на всю ширину страницы */
  break-inside: avoid;
  width: 100%;
}
```

**Поведение:**

* `wide` **всегда** завершает текущие колонки и формирует блок над следующими.
* Контент после `wide` начнётся в **левой** колонке (аналог эффекта `columnreset`).

**Примеры использования:**

```md
Текст в левой колонке…

::: columnbreak
Текст в правой колонке…

::: wide
> Большая карта модуля (во всю ширину)

Дальше — снова левая колонка.
```

---

## Часто встречающиеся сценарии

* **Колонка 1 → колонка 2 → снова колонка 1:**

  ```md
  …слева…
  ::: columnbreak
  …справа…
  ::: columnreset
  …снова слева…
  ```

* **Большой «хиро»-блок во всю ширину между колонками:**

  ```md
  …слева…
  ::: wide
  # Заголовок раздела
  Который идёт уже с левой колонки
  ```

* **Принудительно начать следующий большой раздел с левой:**

  ```md
  ::: columnreset
  # Chapter 3
  ```
